Takeaway

A displacement of zero is not free.

On Intel E-cores, any LEA with both an index and a displacement takes 2 cycles instead of 1, whatever the values. The P-core on the same chip doesn’t care.

To sum up: equivalent instructions can differ in time only because of the addressing mode. On E-cores, index plus displacement costs an extra cycle regardless of values or length. The P-core handles every form in one cycle. Which forms are slow depends on the core design, which is why we pinned each measurement to one core type.
