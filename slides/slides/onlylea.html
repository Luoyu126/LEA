Appendix 2

Backup, if asked whether real memory instructions pay too. We asked whether real memory instructions pay the same penalty. We took the same address, base plus index, and timed it with and without a plus-zero displacement in loads, stores and add with a memory operand, both latency and throughput. On both cores, every pair is identical. Only LEA, the top row, gets slower. That fits our hypothesis: a real memory address is likely computed by the load unit’s own address adder, which would take base, index and displacement at once. In our model, LEA on the E-core uses the two-input adder instead. This is consistent with the model; timing alone can’t prove it.
