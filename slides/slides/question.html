The question

Can two instructions that compute the same value take different time, only because the address is encoded differently?

We use LEA, which computes an address without touching memory, so caches can’t interfere.

What the textbooks say (Skylake era)

  • 3-part LEA (base + index + disp): 3 cycles
  • RBP as the base: slow
  • Scale factor (×2, ×4, ×8): free
