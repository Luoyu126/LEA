Two things to set up. First, what we measure: one computation written five ways. Every legal combination of base, index and displacement, with rcx set to zero and every displacement zero, so all five instructions produce exactly the same value in rax and differ only in their encoded bytes. The shortest is three bytes, the longest eight. We write the bytes by hand because an assembler silently drops a plus zero. LEA is the right instruction for this because it does the address arithmetic and never touches memory, so no cache effect can creep in. Index on its own is missing because it cannot be encoded: with no base, x86 always adds a four-byte displacement. Second, where we measure: five cores in three classes, across two laptops. The Core Ultra 9 285H has a Lion Cove P-core, a Skymont E-core and a low-power Crestmont E-core; the i7-13700H has a Raptor Cove P-core and a Gracemont E-core, one generation older than Skymont.
